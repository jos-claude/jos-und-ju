# Remotes & Netzwerk

Status: **Vorschlag**.

- Client → Server: nur **Wünsche** (`BuyBuilding`, `StartTravel` …). Der Server prüft **alles** (Preis, Voraussetzungen, Reichweite).
- Server → Client: Statusänderungen (neue Credits, neues Gebäude).
- Remotes liegen in `ReplicatedStorage.Remotes` und werden vom Server beim Start angelegt.
- Nie dem Client vertrauen: keine Preise oder Mengen vom Client annehmen.
