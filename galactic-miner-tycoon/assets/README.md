# Assets

Modelle, Sounds, Bilder und Icons, die wir benutzen. Die eigentlichen Dateien liegen in Roblox (Place/Toolbox); hier führen wir **Liste und Roblox-ID**, damit nichts doppelt gebaut wird und wir wissen, was woher kommt.

Regeln:
- Jedes Asset in `asset-liste.md` eintragen, **bevor** es im Spiel benutzt wird.
- Namen in Englisch, `PascalCase` (siehe `../technik/namenskonventionen.md`).
- Lizenz/Quelle angeben (selbst gebaut / Roblox-Toolbox).

Modelle, die als Datei ins Repo sollen (`.rbxm`), kommen nach `../src/ReplicatedStorage/Assets/`.
