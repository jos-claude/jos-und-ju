# Entscheidung 003: Sprachen – Doku Deutsch, Code Englisch

- **Status:** Vorschlag
- **Datum:** 11.11.2026
- **Von:** Claude (Vorschlag)

## Entscheidung
- Konzept, Aufträge, Doku: **Deutsch**.
- Code, Script-/Modulnamen, Variablen, Remote-Namen: **Englisch** (Roblox-API und alle Tutorials sind englisch, das vermeidet Mischmasch).
- Texte, die der Spieler sieht (UI), kommen später aus einer Textdatei, damit wir sie übersetzen können.
