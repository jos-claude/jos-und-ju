| Basis / Raumstation | Base / Station | Das, was der Spieler per Button ausbaut |
| Bauplatz | Plot | Der Bereich eines Spielers für seine Basis |
| Bohrer | Drill | Baut automatisch Rohstoffe ab |
| Förderband | Conveyor | Transportiert Rohstoffe |
| Fabrik | Factory | Verarbeitet Rohstoffe |
| Silo / Lager | Silo / Storage | Lagert Ressourcen |
| Rohstoff | Raw Resource | Unverarbeitete Ressource |
| Fortgeschrittenes Material | Advanced Material | Verarbeitete Ressource |
| Erkundungsplanet | Exploration Planet | Fremde Welt zum Abbauen |
| Raumschiff / Rakete | Spaceship / Rocket | Reisemittel |
| Forschungslabor | Research Lab | Schaltet Technik frei |
| Techbaum | Tech Tree | Übersicht aller Forschungen |
| Laserpickel | Laser Pick | Abbauwerkzeug |
| Geologischer Scanner | Geological Scanner | Findet Vorkommen |
| Gefahr | Hazard | Bedrohung auf Planeten |
| Credits | Credits | Normale Währung |
