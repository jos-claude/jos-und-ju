# Release-Checkliste

## Spiel
- [ ] Spielbar von Anfang bis Ende der aktuellen Inhalte
- [ ] Getestet auf PC **und** Handy (UI, Steuerung)
- [ ] Speichern/Laden getestet (Spiel verlassen und wieder beitreten)
- [ ] Keine Fehler in der Ausgabe

## Roblox-Seite
- [ ] Name, Beschreibung, Icon, Thumbnails
- [ ] Altersfreigabe-Fragebogen ausgefüllt
- [ ] Gamepasses/Dev-Products eingerichtet (falls vorhanden)
- [ ] Alle Sounds/Bilder/Modelle sind erlaubt (eigene oder Roblox-Bibliothek)

## Nach dem Start
- [ ] Analytics ansehen, Feedback sammeln
