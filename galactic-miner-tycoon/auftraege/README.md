# Aufträge

So geben wir uns gegenseitig Aufgaben.

- `offen/` – noch zu erledigen. `erledigt/` – fertig (mit Abschnitt „Ergebnis“).
- Neuer Auftrag: `_VORLAGE.md` kopieren → `offen/NNN-von-an-titel.md` (z. B. `001-jos-an-ju-heimatplanet-welt.md`). Nummer = höchste Nummer in `offen/` **und** `erledigt/` + 1.
- Nach dem Anlegen: committen und pushen, damit der andere ihn nach dem nächsten `git pull` sieht.
- Fertig? „Ergebnis“ ausfüllen, Status auf „erledigt“, Datei nach `erledigt/` verschieben, pushen. Dazu passende Häkchen in `../checklisten/meilensteine.md` setzen.
